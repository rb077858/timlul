# שירות ההורדה מיוטיוב

אתר תמלולי רץ על Cloudflare Workers, ושם אי אפשר להריץ את `yt-dlp` (התוכנה שמורידה את הקול מיוטיוב). לכן יש שירות קטן נפרד, `server.py`, שרץ על שרת רגיל. האתר שולח לו קישור, מקבל את הקול, ומתמלל אותו כמו קובץ שהועלה. בלי השירות הזה, האפשרות "סרטון מיוטיוב" פשוט לא מופיעה באתר.

## איך מפעילים
1. מכינים סיסמה ארוכה אקראית. זה `YT_AUDIO_TOKEN`.
2. מפעילים את השירות על אחד מאלה (כולם עובדים עם ה-`Dockerfile` שבתיקייה):
   - **שרת וירטואלי (VPS) קטן**: `docker build -t yt-audio . && docker run -d -p 8080:8080 -e YT_AUDIO_TOKEN=הסיסמה yt-audio`
   - **Fly.io / Render / Railway / Google Cloud Run**: מעלים את התיקייה כשירות Docker ומגדירים את המשתנה `YT_AUDIO_TOKEN`.
3. מוודאים שהוא חי: `https://הכתובת-שלכם/health` מחזיר `{"ok": true}`.
4. ב-Cloudflare (Worker `timlul` ← Settings ← Variables and Secrets) מוסיפים:
   - `YT_AUDIO_URL`: הכתובת של השירות (למשל `https://yt-audio.example.com`)
   - `YT_AUDIO_TOKEN`: אותה סיסמה (מסוג Secret)

## מה חשוב לדעת
- **יוטיוב חוסמת לפעמים שרתים בענן** ("Sign in to confirm you're not a bot"). אם זה קורה, אפשר לתת לשירות קובץ `cookies.txt` של חשבון יוטיוב (עדיף חשבון נפרד, לא האישי) דרך `YTDLP_COOKIES`, או לשלוח את הבקשות דרך פרוקסי עם `YTDLP_EXTRA="--proxy ..."`. שרת ביתי או VPS רגיל חסום פחות מ-Cloud Run.
- **yt-dlp מתיישן**: יוטיוב משנה דברים, ולכן כל כמה שבועות כדאי לבנות מחדש את ה-Docker (`pip install -U yt-dlp`) או להריץ `yt-dlp -U`.
- **תנאי השימוש של יוטיוב** אוסרים הורדה של סרטונים שלא דרך האתר שלה. האחריות על השימוש היא עליכם (כדאי להגביל לתכנים שלכם או כאלה שמותר לתמלל).
- בשירות: רק קישורי יוטיוב, עד שעתיים ו-180MB, שתי הורדות במקביל, ושום דבר לא נשמר. האתר מגביל כל משתמש ל-30 סרטונים ביום.
- בדיקה (בלי רשת, עם yt-dlp מדומה): `python3 test_server.py`.

## הגדרות השירות (משתני סביבה)
`YT_AUDIO_TOKEN` (חובה), `PORT` (8080), `MAX_SECONDS` (7200), `MAX_BYTES`, `MAX_JOBS` (2), `YTDLP_BIN`, `YTDLP_COOKIES`, `YTDLP_EXTRA`.
