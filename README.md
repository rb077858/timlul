# תמלולי

אתר בתשלום חודשי לתמלול קבצי אודיו ווידאו עם OpenAI. ההתחברות, התשלומים (PayPal המרכזי) והניהול דרך reem.bi, ושליחה במייל דרך Resend. רץ על Cloudflare Workers בתוכנית החינמית.

**📘 מדריך הקמה מלא בעברית: [docs/SETUP-HE.md](docs/SETUP-HE.md)**

## מבנה
| קובץ | מה יש בו |
|---|---|
| `src/index.js` | ה-API: מכסות, תמלול, מייל, ונתוני האתר לדשבורד reem.bi (`/api/admin/manifest`) |
| `src/sso.js` | חשבון reem.bi: זיהוי המשתמש והתוכנית שלו (דקות והרשאות מה-JSON בדשבורד) |
| `src/plans.js` | ברירות מחדל לדקות והרשאות, ומחירי OpenAI לסטטיסטיקות |
| `src/store.js` | בסיס הנתונים (Durable Object עם SQLite): שימוש (כולל כמה ממנו מחבילות) ומגבלות מייל |
| `src/openai.js` | העברת השמע ל-OpenAI בזרימה, בלי לשמור אותו; ותמלול לפי דוברים (`diarizeWav`) |
| `src/youtube.js` | קישור יוטיוב: בקשת הקול משירות ההורדה (`tools/youtube-audio`) |
| `src/mail.js` | שליחה ב-Resend |
| `public/` | האתר: `index.html`, `app.js` (כולל דף המחירים דרך `auth.billing`), `audio.js` (עיבוד השמע בדפדפן), `export.js` (הורדה כ-Word, PDF וטקסט, בעברית), `speakers.js` (תמלול לפי דוברים) |
| `tools/youtube-audio/` | שירות קטן להורדת הקול מיוטיוב, לא חלק מה-Worker. ההוראות בתוכו |
| `test/` | בדיקות אוטומטיות עם כל השירותים החיצוניים מדומים |

תוכניות, מחירים, מנויים, חבילות דקות, קודי קופון וכל הניהול נמצאים ב-login.reembir.com/admin ← אתרים ← תמלולי.

## פקודות
```bash
npm install
npm run dev     # http://localhost:8787 (צריך קובץ .dev.vars, ראה .dev.vars.example)
npm test
```

## הורדה, דוברים ויוטיוב
- **הורדה**: Word (`.docx`), PDF וטקסט, מתוך התמלול והסיכום. הכול נעשה בדפדפן, בלי העלאה. ה-PDF נוצר מהדפסת עמוד מעוצב (בוחרים "שמירה כ-PDF"), כך שהעברית והטקסט נשארים תקינים וניתנים לסימון.
- **זיהוי דוברים**: תיבת סימון בהגדרות. עולה כמו המודל המדויק. ברירת המחדל: מי שיש לו את המודל המדויק. אפשר לשלוט בנפרד ב-JSON של התוכנית בדשבורד: `{"diarize": true}` או `false`. המודל: `MODEL_DIARIZE` (ברירת מחדל `gpt-4o-transcribe-diarize`). הערה: OpenAI הודיעה שכל מודלי התמלול הנוכחיים, כולל זה, ייסגרו ב-26.2.2027. אפשר להחליף את שמות המודלים דרך `MODEL_FAST`, `MODEL_STRONG` ו-`MODEL_DIARIZE` בלי לשנות קוד.
- **יוטיוב**: מופיע רק כש-`YT_AUDIO_URL` ו-`YT_AUDIO_TOKEN` מוגדרים. ראו `tools/youtube-audio/README.md`.
