# מדריך הקמה: אתר התמלול

המדריך עובר שלב אחרי שלב על כל מה שצריך לעשות כדי שהאתר יעלה לאוויר. עושים את השלבים לפי הסדר. כל שלב לוקח בין 2 ל-10 דקות.

**מה נקבל בסוף:** אתר בכתובת `https://timlul.reembir.com` (אפשר לבחור שם אחר) עם התחברות דרך חשבון reem.bi, תשלום חודשי ב-PayPal, תמלול דרך OpenAI ושליחה במייל דרך Resend.

**איך זה בנוי (בקצרה):**
- הכול רץ על **Cloudflare Workers** בתוכנית החינמית: גם הדפים של האתר וגם השרת.
- בסיס הנתונים הוא **Durable Object** (SQLite) של Cloudflare. הוא נוצר לבד בפריסה הראשונה, וגם הוא כלול בתוכנית החינמית.
- הקובץ מעובד **בדפדפן של המשתמש**: השמע מופרד מהווידאו, מומר לפורמט קטן ונחתך לקטעים של 5 דקות. רק השמע נשלח לשרת, והשרת מעביר אותו ל-OpenAI.
- השרת סופר דקות לפי אורך השמע האמיתי, כך שאי אפשר לרמות את המכסה.
- תמלולים **לא נשמרים** בשרת. הם נשמרים רק בדפדפן של המשתמש.

## שלב 1: מפתח OpenAI

1. היכנס ל-https://platform.openai.com/api-keys
2. לחץ **Create new secret key**.
   - Name: `timlul`
   - Project: הפרויקט שלך (או Default project)
   - Permissions: **All** (או Restricted עם הרשאת **Write** ל-**Audio**)
3. לחץ **Create secret key** והעתק את המפתח (מתחיל ב-`sk-`). **הוא מוצג רק פעם אחת.**
4. רשום בקובץ הזמני: `OPENAI_API_KEY = sk-...`
5. **מומלץ מאוד:** קבע תקרת הוצאה, כדי שבעיה לא תעלה לך הרבה כסף:
   - היכנס ל-https://platform.openai.com/settings/organization/limits
   - ב-**Usage limits** קבע תקרה חודשית (למשל 30$) והתראה (למשל 15$).
6. ודא שיש יתרה בחשבון: https://platform.openai.com/settings/organization/billing

> המודלים שהאתר משתמש בהם: **מהיר** = `gpt-4o-mini-transcribe` (כ-0.003$ לדקה), **מדויק** = `gpt-4o-transcribe` (כ-0.006$ לדקה). אם OpenAI ישחררו מודל חדש, אפשר להחליף אותו בלי לשנות קוד (ראה "הגדרות אופציונליות" בסוף).

## שלב 2: מפתחות PayPal

PayPal נותן שני סוגי מפתחות: **Sandbox** (כסף מדומה, לבדיקות) ו-**Live** (כסף אמיתי). מומלץ להתחיל עם Sandbox, לבדוק שהכול עובד, ורק אז לעבור ל-Live (שלב 9).

### 2א. מפתחות Sandbox לבדיקות
1. היכנס ל-https://developer.paypal.com/dashboard/ עם החשבון העסקי שלך.
2. למעלה בחר את המתג **Sandbox**.
3. בתפריט: **Apps & Credentials** ← **Create App**.
   - App Name: `timlul`
   - Type: **Merchant**
   - לחץ **Create App**.
4. בדף שנפתח תראה:
   - **Client ID** ← רשום בקובץ: `PAYPAL_CLIENT_ID = ...`
   - **Secret key 1** ← לחץ על העין או **Show**, והעתק: `PAYPAL_CLIENT_SECRET = ...`
5. ודא שבאפליקציה, תחת **Features**, האפשרות **Subscriptions** (או **Recurring payments / Vault**) מסומנת. בדרך כלל זה מסומן כברירת מחדל.
6. כדי לבדוק תשלום תצטרך "קונה מדומה":
   - בתפריט: **Testing Tools** ← **Sandbox Accounts**.
   - יש שם חשבון **Personal** שנוצר אוטומטית. לחץ על שלוש הנקודות ← **View/Edit account** והעתק את המייל והסיסמה שלו. איתם "תשלם" בבדיקה.

### 2ב. מפתחות Live (לשלב 9, אפשר כבר עכשיו)
אותו תהליך עם המתג **Live** למעלה. שמור אותם בצד, עוד לא מדביקים אותם.

> **מטבע:** האתר מוגדר לשקלים (ILS). אם PayPal לא מאפשר לחשבון שלך לקבל שקלים, ראה "שינוי מטבע" בסוף המדריך.

## שלב 3: Resend (שליחת התמלול במייל)

1. היכנס ל-https://resend.com/domains וודא שהדומיין שלך (למשל `reembir.com`) מופיע עם סטטוס **Verified**.
2. היכנס ל-https://resend.com/api-keys ← **Create API Key**.
   - Name: `timlul`
   - Permission: **Sending access**
   - Domain: הדומיין המאומת שלך
   - לחץ **Add** והעתק את המפתח (מתחיל ב-`re_`).
3. רשום בקובץ: `RESEND_API_KEY = re_...`
4. בחר כתובת שולח מהדומיין המאומת ורשום בקובץ:
   `MAIL_FROM = תמלול <timlul@reembir.com>`
   (החלק שלפני ה-@ יכול להיות כל מילה. הדומיין חייב להיות זה שאומת ב-Resend.)

> המייל נשלח תמיד רק לכתובת של המשתמש המחובר, עם קובץ TXT מצורף. כל משתמש מוגבל ל-20 מיילים ביום, כדי שאף אחד לא ינצל את זה לשליחת ספאם.

## שלב 4: העלאת האתר ל-Cloudflare

1. היכנס ל-https://dash.cloudflare.com
2. בתפריט הצד: **Compute (Workers)** ← **Workers & Pages** (בחשבונות מסוימים מופיע ישר **Workers & Pages**).
3. לחץ **Create** (או **Create application**).
4. בחר **Import a repository** (תחת לשונית **Workers**, לא Pages).
5. אם זו הפעם הראשונה, תתבקש לחבר את GitHub:
   - לחץ **Connect GitHub**, אשר את ההתקנה של **Cloudflare Workers and Pages**.
   - בחר **Only select repositories** וסמן את `timlul` (או **All repositories**).
6. בחר את המאגר **rb077858/timlul**.
7. במסך ההגדרות:
   - **Project name**: `timlul` (חייב להיות בדיוק השם הזה, כי זה השם שמופיע בקובץ `wrangler.toml`)
   - **Build command**: להשאיר ריק
   - **Deploy command**: `npx wrangler deploy`
   - **Root directory** (אם יש): להשאיר ריק או `/`
   - **Production branch**: `main`
8. לחץ **Deploy** וחכה 1-2 דקות עד שתראה ✓ ירוק.
9. בסוף תקבל כתובת זמנית בסגנון `https://timlul.<שם-החשבון>.workers.dev`. **רשום אותה בקובץ**, תצטרך אותה בשלב 6.

מעכשיו, **כל שינוי שנכנס ל-main ב-GitHub עולה לאתר אוטומטית** תוך דקה-שתיים.

## שלב 5: מפתחות והגדרות ב-Cloudflare

1. ב-Cloudflare, פתח את ה-Worker **timlul** ← לשונית **Settings** ← **Variables and Secrets**.
2. לחץ **+ Add** לכל אחת מהשורות בטבלה. בשדה **Type** בחר מה שכתוב בעמודה "סוג":

| Variable name | סוג | ערך |
|---|---|---|
| `OPENAI_API_KEY` | **Secret** | המפתח מ-OpenAI (`sk-...`) |
| `PAYPAL_CLIENT_ID` | Text | Client ID של PayPal (Sandbox בינתיים) |
| `PAYPAL_CLIENT_SECRET` | **Secret** | Secret של PayPal (Sandbox בינתיים) |
| `PAYPAL_ENV` | Text | `sandbox` (בשלב 9 תשנה ל-`live`) |
| `RESEND_API_KEY` | **Secret** | המפתח מ-Resend (`re_...`) |
| `MAIL_FROM` | Text | `תמלול <timlul@reembir.com>` |
| `ADMIN_EMAILS` | Text | המייל שלך שאיתו אתה מתחבר ל-reem.bi. כמה מנהלים: מופרדים בפסיק |
| `SSO_SITE_KEY` | **Secret** | מפתח השרת מהדשבורד reem.bi. יוצרים אותו בשלב 10, אפשר להוסיף אותו אז |

3. לחץ **Deploy** (או **Save and deploy**) בתחתית.

> הסודות (Secret) מוצפנים ולא נמחקים בפריסות הבאות. גם המשתנים מסוג Text נשמרים, כי בקוד מוגדר `keep_vars = true`.

## שלב 6: כתובת קבועה (דומיין)

1. ב-Worker **timlul** ← **Settings** ← **Domains & Routes** ← **+ Add** ← **Custom domain**.
2. כתוב: `timlul.reembir.com` (או כל תת-דומיין אחר שתרצה).
3. לחץ **Add domain**. Cloudflare יוצר לבד את רשומת ה-DNS ואת תעודת ה-SSL. זה לוקח עד כמה דקות.
4. בדוק שהכתובת `https://timlul.reembir.com` נפתחת ומציגה את האתר.

> אם בחרת כתובת אחרת, השתמש בה בכל מקום שכתוב `timlul.reembir.com` בהמשך.

1. היכנס ל-https://login.reembir.com/admin ← לשונית **אתרים** ← **+ אתר חדש**.

| שדה | מה לכתוב |
|---|---|

| **שם** | `תמלול` |

| **תיאור** | `תמלול קבצי אודיו ווידאו` |
| **כתובות חזרה מותרות** | שלוש שורות (ראה למטה) |

**כתובות חזרה מותרות** (כל אחת בשורה נפרדת, עם `/` בסוף). את השורה השנייה תחליף בכתובת ה-workers.dev שרשמת בשלב 4:

**תוכניות בדשבורד:** יוצרים אותן בשלב 10, אחרי שהאתר עובד.

1. היכנס ל-`https://timlul.reembir.com/admin.html`
2. לחץ **התחברות** והתחבר עם המייל ששמת ב-`ADMIN_EMAILS`.
3. בכרטיס **הגדרות שחסרות** כל השורות צריכות להיות ✓ ירוק. אם משהו אדום, חזור לשלב 5.
4. בכרטיס **PayPal (בדיקות - sandbox)** לחץ **יצירת תוכניות ב-PayPal** ← אשר.
5. תראה ✓ ורשימה של 3 תוכניות עם מזהים שמתחילים ב-`P-`. זה אומר שנוצרו ב-PayPal "מוצר" ושלוש תוכניות מנוי חודשיות.

מעכשיו, בדף הראשי, כפתורי PayPal מופיעים בכרטיסי התוכניות (למשתמשים מחוברים).

### בדיקה מלאה (עם כסף מדומה)
1. פתח את `https://timlul.reembir.com` בחלון גלישה בסתר (Incognito) והתחבר.
2. אמור להופיע "חינם" עם 10 דקות.
3. העלה קובץ קצר (דקה-שתיים), בחר **מהיר**, לחץ **תמלול**. אמור להופיע טקסט.
4. בדוק **הורדה כקובץ TXT** ו-**העתקה**. המודל המדויק ו**שליחה למייל** נעולים (🔒) בתוכנית החינמית. זה תקין.
5. גלול ל**תוכניות ומחירים**, לחץ על כפתור PayPal בתוכנית **בסיסי**, והתחבר עם **חשבון ה-Sandbox Personal** מסוף שלב 2א. אשר.
6. כרטיס התוכנית אמור להתחלף ל"בסיסי" עם 180 דקות. עכשיו נסה גם את המודל **המדויק** ואת **שליחה למייל שלי**.
7. לחץ **ביטול מנוי** ואשר. התוכנית אמורה להישאר "בסיסי" עד סוף החודש, עם הכיתוב "המנוי בוטל".
8. ב-`admin.html` תראה את המנוי בטבלה.

## שלב 10: ניהול המנויים מהדשבורד reem.bi

אחרי השלב הזה, כל מי שמשלם מופיע בדשבורד reem.bi עם התוכנית שלו ותאריך התפוגה, ואפשר לנהל משם:
- לתת למישהו תוכנית בחינם, לזמן מוגבל או לתמיד
- להאריך או להוריד תוכנית
- לחסום משתמש
- לשנות כמה דקות יש בכל תוכנית, ולתת למשתמש מסוים דקות נוספות

### 10א. יצירת התוכניות בדשבורד
1. היכנס ל-https://login.reembir.com/admin ← **אתרים** ← לחץ על **תמלול** כדי לפתוח אותו.
2. למטה, בחלק **תוכניות**, הוסף 4 שורות. בכל שורה ממלאים מזהה, שם וההרשאות (JSON), ולוחצים **+ הוספה**:

| מזהה | שם | הרשאות (JSON) |
|---|---|---|
| `timlul:free` | חינם | `{"minutes": 10, "strong": false, "email": false}` |
| `timlul:basic` | בסיסי | `{"minutes": 180, "strong": true, "email": true}` |
| `timlul:pro` | מקצועי | `{"minutes": 600, "strong": true, "email": true}` |
| `timlul:business` | עסקי | `{"minutes": 1500, "strong": true, "email": true}` |

   **חשוב:** המזהים חייבים להיות **בדיוק** כמו בטבלה, באנגלית ובאותיות קטנות.
3. למעלה, בהגדרות האתר, ב-**תוכנית ברירת מחדל** בחר **חינם** (`timlul:free`) ולחץ **שמירה**.

מה אומרות ההרשאות:
- `minutes`: כמה דקות יש בחודש
- `strong`: האם מותר להשתמש במודל המדויק
- `email`: האם מותר לשלוח את התמלול במייל

### 10ב. מפתח שרת
1. באותו מסך, בחלק **מפתח שרת**, לחץ **יצירת מפתח**.
2. יופיע מפתח שמתחיל ב-`rsk_`. לחץ **העתקה**. **הוא מוצג רק פעם אחת.**
3. ב-Cloudflare ← Worker **timlul** ← **Settings** ← **Variables and Secrets** ← **+ Add**:
   - Type: **Secret**
   - Name: `SSO_SITE_KEY`
   - Value: המפתח שהעתקת
4. לחץ **Deploy**.

### 10ג. בדיקה
1. היכנס ל-`https://timlul.reembir.com/admin.html`.
2. בכרטיס **חיבור ל-reem.bi** אמור להופיע ✓ "מחובר", בלי תוכניות חסרות.
3. בשורה "הגדרות פעילות" תראה את הדקות שהגדרת בדשבורד.

### איך מנהלים מנויים מעכשיו
| מה רוצים | איפה עושים |
|---|---|
| לראות מי מנוי ועד מתי | דשבורד reem.bi ← **משתמשים** (סינון לפי האתר תמלול או לפי תוכנית) |
| לתת למישהו תוכנית בחינם | דשבורד ← משתמשים ← המשתמש ← תמלול ← בוחרים תוכנית ותאריך תפוגה ← שמירה |
| לתת למשתמש אחד יותר דקות | אותו מקום, בהרשאות אישיות: `{"minutes": 1000}` |
| לתת למשתמש אחד דקות ללא הגבלה | אותו מקום, בהרשאות אישיות: `{"unlimited": true}`. זו לא תוכנית ואף אחד אחר לא רואה אותה. המשתמש מקבל גם את המודל המדויק ומייל. כדי לבטל, מוחקים את השורה |
| לשנות דקות לכל המנויים בתוכנית | דשבורד ← אתרים ← תמלול ← משנים את ה-JSON של התוכנית. חל תוך 5 דקות |
| לחסום משתמש | דשבורד ← משתמשים ← המשתמש ← חסום |
| לבטל חיוב של מנוי משלם | ב-PayPal (Pay & Get Paid ← Subscriptions), או שהמשתמש לוחץ "ביטול מנוי" באתר |

כמה דברים שכדאי לדעת:
- **כשמישהו משלם או מחדש מנוי**, האתר מעדכן לבד את התוכנית ואת תאריך התפוגה בדשבורד.
- **הדשבורד לא מבטל חיובים ב-PayPal.** אם תוריד בדשבורד תוכנית של מישהו שמשלם, הוא עדיין יקבל את מה ששילם עליו, וב-PayPal ימשיך להיות מחויב. כדי להפסיק לחייב אותו מבטלים ב-PayPal.
- **אם יש למשתמש גם תוכנית מהדשבורד וגם מנוי ב-PayPal**, הוא מקבל את הגבוהה מביניהן.
- **שינוי דקות או הרשאות בדשבורד** יכול לקחת עד 5 דקות להופיע באתר.
- **בלי `SSO_SITE_KEY`** האתר ממשיך לעבוד, אבל המנויים לא יופיעו בדשבורד וקודי מתנה לא יעבדו.

## קודי קופון

את הקודים יוצרים ומנהלים ב-`admin.html` ← **קודי קופון**. יש ארבעה סוגים:

| סוג | דוגמה | מה קורה |
|---|---|---|
| **הנחה באחוזים** | 50% ל-3 חודשים | המחיר מוזל בחודשים הראשונים, ואחר כך מחיר רגיל. 0 חודשים = הנחה לכל תקופת המנוי |
| **הנחה בשקלים לחודש** | ₪5 פחות, לתמיד | כמה שקלים יורדים מהמחיר החודשי. אם ההנחה גדולה מהמחיר, החודשים האלה חינם |
| **חודשים ראשונים חינם** | חודש ראשון חינם | הלקוח נרשם ב-PayPal עם כרטיס ולא משלם בתקופה הזו. אחר כך מחויב במחיר רגיל, אלא אם ביטל |
| **מתנה בלי תשלום** | 3 חודשים "מקצועי" | בלי PayPal ובלי כרטיס. התוכנית נרשמת בדשבורד reem.bi עם תאריך תפוגה. בסוף חוזרים לחינם. דורש את שלב 10 |

**יצירת קוד:**
1. **קוד:** כותבים מילה באנגלית, למשל `SUMMER50`, או לוחצים **אקראי**.
2. **סוג** ו**ערך:** אחוז או סכום, ולכמה חודשים.
3. **לאילו תוכניות:** בלי סימון = כל התוכניות בתשלום. במתנה בוחרים תוכנית אחת.
4. **מקסימום שימושים** (0 = בלי הגבלה), **תאריך תפוגה** (לא חובה), **הערה** לעצמך.
5. לוחצים **יצירת קוד**.

**איך הלקוח משתמש בקוד:**
- כותב אותו בשדה **"יש לך קוד קופון?"** מעל התוכניות ולוחץ **החלה**. המחירים בכרטיסים מתעדכנים, וכפתורי PayPal גובים את המחיר המוזל. בקוד מתנה מופיע כפתור **הפעלת המתנה**.
- או מקבל ממך קישור: בטבלת הקודים לוחצים **קישור**, ומקבלים כתובת כמו `https://timlul.reembir.com/?coupon=SUMMER50`. מי שנכנס דרכה מקבל את הקוד אוטומטית, גם אם הוא צריך להתחבר קודם.

**כללים:**
- כל אדם יכול להשתמש בכל קוד **פעם אחת**.
- קוד חל רק בהרשמה למנוי חדש או במעבר בין תוכניות. אי אפשר להחיל אותו על מנוי שכבר פעיל.
- **השבתה** עוצרת שימושים חדשים. מי שכבר נרשם עם הקוד ממשיך לקבל את ההנחה שלו.
- **מחיקה** אפשרית רק לקוד שאף אחד לא השתמש בו. קוד שנוצל אפשר רק להשבית.
- מאחורי הקלעים, לכל קוד הנחה נוצרת ב-PayPal תוכנית מנוי נפרדת. זה קורה לבד בפעם הראשונה שמישהו מחיל את הקוד, ולא צריך לעשות שום דבר ב-PayPal.

**המודל המדויק נספר כפול:** דקה במודל המדויק מורידה 2 דקות מהמכסה, כי הוא עולה ל-OpenAI בערך פי 2. כך הרווח שלך זהה בשני המודלים.

**חלקים שקטים לא נספרים:** קטעים של 5 דקות שאין בהם שום קול מדולגים ולא נשלחים ל-OpenAI.

> שים לב: מע"מ ומס הכנסה הם עניין לרואה החשבון שלך. אם אתה עוסק מורשה, ייתכן שהמחירים צריכים לכלול מע"מ.

### שינוי דקות או הרשאות
בדשבורד reem.bi ← **אתרים** ← **תמלול** ← משנים את ה-JSON של התוכנית (ראה שלב 10). השינוי חל על כולם תוך 5 דקות, ולא צריך לשנות שום דבר ב-PayPal.

### שינוי מחירים
1. ב-GitHub פתח את הקובץ `src/plans.js` ← לחץ על העיפרון (Edit).
2. שנה את `price`. למשל `basic: { name: 'בסיסי', price: 12, ... }`.
3. לחץ **Commit changes**. האתר מתעדכן לבד תוך דקה-שתיים.
4. היכנס ל-`admin.html` ולחץ שוב **יצירת תוכניות ב-PayPal**. מנויים קיימים ממשיכים במחיר הישן, ומנויים חדשים משלמים את החדש. קודי קופון מתעדכנים למחיר החדש לבד.

> הדקות ב-`plans.js` (`credits`) משמשות רק אם אין לתוכנית `minutes` בדשבורד.
